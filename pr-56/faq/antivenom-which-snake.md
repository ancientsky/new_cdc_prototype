# 被龜殼花或其他毒蛇咬到要打哪種血清？認不出是哪種蛇怎麼辦？

> 權責單位：檢驗及疫苗研製中心 · 最後審閱：2026-10-10 · 下次審閱：2027-04-10 · 授權：OGDL-1.0 · ID：faq.antivenom-which-snake
> ⚠ 本頁依公開資料整理，尚待權責單位（檢驗及疫苗研製中心）逐項確認。緊急狀況請撥 119；用藥與處置以醫師判斷為準。

疾管署供應 4 種抗蛇毒血清，依蛇種對應如下：

- 被龜殼花咬傷：龜殼花屬出血性蛇毒，對應的血清是抗龜殼花及赤尾鮐蛇毒血清。
- 被赤尾鮐（赤尾青竹絲）咬傷：對應的血清是抗龜殼花及赤尾鮐蛇毒血清。
- 被百步蛇咬傷：百步蛇屬出血性蛇毒，對應的血清是抗百步蛇毒血清。
- 被雨傘節或飯匙倩（眼鏡蛇）咬傷：兩者屬神經性蛇毒，對應的血清是抗雨傘節及飯匙倩蛇毒血清。
- 被鎖鏈蛇咬傷：鎖鏈蛇兼具出血性與神經性蛇毒，對應的血清是抗鎖鏈蛇毒血清。

要不要使用、使用哪一種與用多少，由醫師依傷口與症狀判斷。認不出是哪一種蛇也不要延誤就醫，把記得的顏色、花紋、頭形告訴醫護人員即可，緊急請撥 119。
