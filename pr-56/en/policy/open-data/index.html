Unless otherwise marked, text, statistics and API data are released under the Open Government Data License, version 1.0, compatible with CC BY 4.0. You may copy, adapt and use them commercially. Please attribute "Source: Taiwan Centers for Disease Control (data date YYYY-MM-DD)" with the original URL, do not imply endorsement, and cite the current version of guidelines. Datasets marked "licence pending" or third-party media are excluded. Use the data catalogue, the /v1/ API with OpenAPI docs, or NIDSS.
