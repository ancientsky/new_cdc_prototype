# 無障礙聲明

> 權責單位：資訊室 · 最後審閱：2026-09-15 · 下次審閱：2027-09-15 · 授權：OGDL-1.0 · ID：page.accessibility

## 一、目標
本站依數位發展部「網站無障礙規範」，以 **新版網站無障礙規範 AA 等級（對應 WCAG 2.2 AA）**為目標設計與開發（數位發展部於 2026 年 5 月 29 日修正、同年 11 月 30 日施行，新增目標尺寸等 WCAG 2.2 項目）。

## 二、2026 年 9 月實測結果
以自動化檢測工具與人工檢測（鍵盤操作、NVDA 與 VoiceOver 螢幕閱讀器、200% 放大）測試首頁、疾病頁、問答頁、新聞稿、文件頁與資料目錄：

| 項目 | 結果 |
| --- | --- |
| 每頁單一標題階層、跳至主要內容連結 | 符合 |
| 全站可用鍵盤操作，焦點清楚可見 | 符合 |
| 文字與背景對比 ≥ 4.5:1 | 符合 |
| 問答結果以 aria-live 即時朗讀 | 符合 |
| 收合區塊使用原生 details／summary | 符合 |
| 趨勢圖提供文字摘要與資料表 | 符合 |
| 多語頁面標示正確 lang 屬性 | 符合 |
| 部分 PDF 正本未提供標記 | **部分符合**：已提供機讀版 Markdown 替代 |
| 外部嵌入影片字幕 | **部分符合**：新影片皆有字幕，舊影片持續補齊 |

## 三、已知限制與改善時程
- 歷年 PDF 文件將於 2027 年 6 月前完成標記或以機讀版取代。
- 2024 年以前之宣導影片字幕將於 2027 年 3 月前補齊。
