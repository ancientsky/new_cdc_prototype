# 疫情統計數字可以到哪裡查？

> 權責單位：疫情中心 · 最後審閱：2026-08-31 · 下次審閱：2027-03-03 · 授權：OGDL-1.0 · ID：faq.stats-where-data · 依據：dataset.nidss

可以利用：

- **傳染病統計資料查詢系統（NIDSS）**：可依疾病、年份、縣市、年齡查詢法定傳染病病例數。
- **疾管署資料開放平台**：提供 CSV、JSON 與 API，例如登革熱每日確定病例、類流感就診人次。
- **流感速訊**與每週疫情報導：說明當週流感與腸病毒等監測重點。

本站的「開放資料與統計」頁也整理了常用資料集，並標示資料日、權責單位與授權。
