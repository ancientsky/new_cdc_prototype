# 公衛醫療專業人員使用說明

> 給誰看：醫師、護理人員、感染管制人員、檢驗人員、地方衛生單位同仁。
> 對應頁面：[專業人員專區](https://ancientsky.github.io/new_cdc_prototype/pro/)、[使用指南](https://ancientsky.github.io/new_cdc_prototype/guide/) 的「公衛醫療專業人員怎麼用」。
> 原則：**公開指引不設登入門檻。** 登入（正式環境）只用來個人化，例如保存角色、訂閱與常用作業。原型中的「○○醫院 感染管制室 · 已登入」是示意畫面。

## 一、進入專業模式

有三種方式，效果相同：

1. 點頁首右上「醫事與防疫人員」。
2. 在任何頁面網址後面加上 `?view=pro`。
3. 直接開啟 [/pro/](https://ancientsky.github.io/new_cdc_prototype/pro/)。

專業模式會記在這台瀏覽器（localStorage `cdc.view`）。切回民眾模式請點頁首的「民眾」，或加 `?view=public`。

專業模式與民眾模式讀的是**同一份內容**，差別只在呈現方式：

| | 民眾模式 | 專業模式 |
| --- | --- | --- |
| 來歷條 | 一行：權責單位 · 最後審閱 | 完整：權責、版次（例：v2026-09，取代 v2026-06）、生效日、審閱日（最後／下次）、對象、適用地區 |
| 答案 | 白話整理 | 引用手冊條次與生效日，不做白話化 |
| 來源卡 | 預設收合 | 預設展開 |
| 可引用的內容 | 公開內容 | 另含專業版文件庫與致醫界通函（僅限**現行版**） |
| 額外按鈕 | 有幫助、回報錯誤 | 另有「引用本頁」「訂閱異動」 |

## 二、設定角色

在專區頂端的「您的角色」選擇：醫師、護理、感染管制、檢驗、地方衛生單位。再按一次同一顆可取消。

選擇後，「指引與手冊版本異動」和「常用作業」會依角色重新排序，符合你角色的項目排在前面並加底色。文件是否適用哪些角色，由文件的 `roles` 欄位決定，由權責單位維護。角色只存在你的瀏覽器（localStorage `cdc.role`），不上傳。

## 三、專業問答

專區中間的問題框，預設提示是「登革熱檢體送驗的容器與時限」。標籤寫明「專業模式：引用手冊條次與生效日，不做白話化」。

怎麼問比較準：

- 寫出病名或主題，加上你要查的面向：「登革熱 檢體 容器 時限」。
- 問規定而不是問判斷：「通報時限」「病例定義的實驗室條件」可以；「這個病人要不要通報」屬於個案判斷，系統會拒答，請對照病例定義或洽所轄衛生局。

送出後會到 `/ask/?q=…&view=pro`。答案具有以下特性：

1. 每句話標註來源編號，來源卡預設展開，內含文件名稱、**版次**、**生效日**、章節、權責單位、最後審閱日。
2. 只引用現行版。被新版取代的文件不會出現在專業問答中；如果你主動搜尋舊版，要到文件庫查閱。
3. 找不到依據時系統會說找不到，並導向文件庫或 1922，不會猜。

## 四、核對版本與異動

專區的「指引與手冊版本異動」列出每份文件：

- 文件名稱與版次。
- 「現行 2026/07 · 前版 2025/11」：現行版與前一版的生效年月。
- 「查看異動對照」：進入文件頁的「異動對照」區，逐段列出前後差異（修改、新增、刪除）。沒有可比較的前版時顯示「無異動 —」。
- 舊版以「（已失效，生效年月）」小字列出，點進去仍可閱讀，但頁首是**紅色橫條**，寫明已被哪一版取代並附連結，且網頁標記為 noindex，搜尋引擎不會收錄。

### 文件頁的版本鏈

每份文件都記錄三件事：**取代誰、被誰取代、生效日**。這些由系統依 `effectiveAt` 自動計算，編輯者不用手填「被誰取代」。核對流程：

1. 打開文件頁，確認頁首沒有紅色或黃色橫條。
2. 看來歷條的「版次」和「生效日」是否是你預期的版本。
3. 展開「版本鏈」，確認現行版是最上面一筆。
4. 若你手上的紙本或院內文件是舊版，用異動對照確認差異是否影響你的作業。

以 MMR 建議為例：108.05.14 版成人評估對象為 1981 年（含）以後出生；114.04.16 版改為 1966 年（含）以後出生、不具麻疹免疫力者，並新增經常接觸外國人的工作者。若你在舊版新聞稿看到「1981 年」，頁首會有橘色加註「所依據的指引已修訂」。

> AI 回答引用到失效版本，被視為嚴重缺陷。評估集中的「版本題」必須全部答對才能發布。

## 五、怎麼引用

專業模式的頁面有「引用本頁」按鈕，點一下複製以下格式：

```
衛生福利部疾病管制署（2026-04-10 審閱）。國內現行 MMR 預防接種建議（114.04.16 版）。https://ancientsky.github.io/new_cdc_prototype/documents/mmr-recommendation.2025-04-16/（114.04.16，生效 2025-04-16）
```

格式規則：**機關名（審閱日 審閱）。標題。網址（版次，生效 生效日）。** 非文件類內容沒有版次，括號省略。

引用到論文、院內公告或衛教單張時，請務必保留審閱日與版次，日後別人才能判斷你引用的是不是現行版。AI 或程式引用時，請一併帶出 `cdc:reviewedAt` 與 `cdc:isCurrent`，見[開發者入口](https://ancientsky.github.io/new_cdc_prototype/developers/#vocab)。

## 六、怎麼訂閱

在專區右欄「我的訂閱」點選你關心的項目：登革熱、腸病毒、抗生素抗藥性、致醫界通函（另可加麻疹 / MMR 建議）。已訂閱的項目顯示打勾。

- 勾選「只顯示我訂閱的項目」，版本異動清單只留你訂閱的主題。
- 正式環境：新版發布或內容異動時，以電子郵件通知。
- **原型**：偏好只存在瀏覽器（localStorage `cdc.subscriptions`），**不會寄信**。想收到實際通知，請改用下面兩個管道：
  - 「複製 RSS/Atom 網址」：貼進 Feedly、Outlook 或任何 RSS 閱讀器。網址為 `/feeds/documents.xml`，文件新版發布、現行版異動、舊版失效都會出現。
  - 「下載 .ics 提醒」：把文件的**下次審閱日**加進行事曆，提前 7 天提醒你回來確認有沒有更新。

## 七、通報、送驗與常用作業

「常用作業」四張卡：

| 卡片 | 去哪裡 |
| --- | --- |
| 法定傳染病通報 | 連到現行通報系統 NIDRS（https://nidrs.cdc.gov.tw/），通報本身仍在該系統完成 |
| 檢體送驗規定 | 容器、時限、表單；以專業問答呈現，並附文件條次 |
| 臨床處置指引 | 依病別查詢，連到疾病頁的「診斷與治療」與專業欄位（病例定義、手冊） |
| 感染管制查核 | 醫院、長照機構查核重點 |

法定傳染病通報時限因病別而異（疾病頁頂端的「通報時限」欄位），請以疾病頁和現行通報系統公告為準。

## 八、現在的疫情（專業版）

右欄表格列出疾病、狀態、數字，並連到 NIDSS 與本站 API（`/v1/situation.json`）。狀態四級（平穩、上升、高峰、下降）由疫情中心人工發布；表上標「示意數字」者為原型資料。下載與引用請標明資料日與發布單位。

## 九、機讀版與 API

- 每個內容頁都有同名 `.md`，第一段是治理資訊，之後是本文。例如 `/documents/mmr-recommendation.2025-04-16.md`。失效版第一行就是「本版已由…取代」。
- 文件頁另有 `machineReadableMarkdown` 機讀版本文，可直接匯入院內知識庫。
- 系統整合請看[開發者入口](https://ancientsky.github.io/new_cdc_prototype/developers/)：`/v1/documents.json` 有所有版本與 `isCurrent`、`supersedes`、`supersededBy`；`/v1/redirects.json` 有舊網址對照。
- 授權為政府資料開放授權條款第 1 版，可自由利用，須標示來源。

## 十、發現文件有誤

在文件頁按「回報錯誤」，表單會帶入稽核編號。請寫明：哪一版、哪一章節、您認為正確的內容與依據。回報會交給文件頁首「權責單位」的 Steward。若涉及病例定義或通報規定的歧義，請同時洽所轄地方衛生單位。

## 十一、快速核對清單

臨床或院內作業引用本站內容之前，花 30 秒確認：

- [ ] 頁首沒有紅色（已取代）、黃色（逾期）、橘色（依據已修訂）橫條。
- [ ] 版次、生效日是我要的版本。
- [ ] 最後審閱日在可接受的範圍內。
- [ ] 若是 AI 整理的答案，每一句都有來源編號，且來源卡的版次是現行版。
- [ ] 已複製「引用本頁」格式，保留在我的文件中。
