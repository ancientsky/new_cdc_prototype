快速開始

所有端點都是靜態 JSON，直接 GET 即可；原型部署在 GitHub Pages，免註冊、免金鑰。

curl -s https://ancientsky.github.io/new_cdc_prototype/preview/pr-56/v1/documents.json | jq '.data[] | select(.isCurrent) | {id, version, effectiveAt, supersedes}'

Base URL：https://ancientsky.github.io/new_cdc_prototype/preview/pr-56/v1/。完整描述檔：openapi.json。

meta 外殼

每個 v1/*.json 都長一樣：{ "meta": {…}, "data": … }。

欄位意思
meta.apiAPI 版本，目前 v1。破壞性變更會開 v2，v1 至少並行一年。
meta.generatedAt這份檔案的產生時間（UTC）。每日排程重建，所以最久不超過一天。
meta.license授權代碼，預設 OGDL-1.0；個別資料集例外時在 data 內另有 license。
meta.etag內容雜湊。內容沒變就不變，可做條件式請求（If-None-Match）。
meta.lastModified資料內容最後變動時間，不等於產生時間。
meta.source、meta.docs正本網站與本文件的網址。

原型現況：generatedAt、license、source、docs 已輸出；etag、lastModified 隨 API 輸出模組補齊（GitHub Pages 也會在 HTTP 標頭送出 ETag 與 Last-Modified）。下方範例的時間為建置日 2026-10-01，屬示意。

端點與範例回應

展開每個端點可看到說明與真實建置資料的前兩筆（欄位已縮減，長文字截斷）。

限流與金鑰

原型
免金鑰、免註冊。靜態檔案由 GitHub Pages 與 CDN 提供，沒有應用層限流；請善意使用，建議快取並以 ETag 做條件式請求，輪詢間隔不低於 1 小時（資料每日重建一次）。
正式環境（規劃）
匿名存取維持開放；大量取用者可申請 API 金鑰（X-API-Key），用於聯絡與通知破壞性變更，而不是設門檻。超量時回 429 並附 Retry-After。
穩定性承諾
已發布欄位不改名、不改型別；新增欄位視為相容變更。計畫下架的端點至少提前 90 天在此頁與變更 feed 公告。

變更事件

只擋 /ask/ 與 /admin/（動態查詢結果與後台）。失效版本不靠 robots 隱藏：爬蟲被擋就看不到頁面上的 noindex，改用頁面層級的 <meta name="robots" content="noindex"> 並以 301 導向現行版。
.md 機讀版
每個內容頁都有同名 .md，例如 /diseases/chikungunya.md。第一段是治理資訊（權責、審閱日、版本、授權、正本網址），之後是本文；失效或逾期時第一行就是警示。
JSON-LD
每頁 <head> 內嵌 schema.org 結構（MedicalCondition、FAQPage、NewsArticle、DigitalDocument、Dataset、GovernmentOrganization），並加上自訂 cdc: 治理欄位，詞彙見下節。
sitemap
/sitemap.xml 為索引，另依型別與語言分檔；失效版本不在其中。

cdc: 自訂詞彙表

命名空間 cdc: ＝ https://ancientsky.github.io/new_cdc_prototype/preview/pr-56/developers/#vocab。這些欄位由治理引擎在建置時計算，頁面與 API 一致。

詞彙型別定義
cdc:idstring內容的穩定識別碼，全站唯一，例如 disease.dengue、doc.mmr-recommendation.2025-04-16。引用時以它為準，不要用會變動的網址或加密 ID。
cdc:ownerstring權責單位名稱（對應 content/master/units.json）。這個單位對內容正確性負責，錯誤回報會轉給它。
cdc:reviewedAtdate (YYYY-MM-DD)最後審閱日。由權責單位確認內容仍然正確的日期，不是編輯日。引用時應一併附上。
cdc:nextReviewAtdate | null下次審閱日，系統以 reviewedAt ＋ 審閱週期計算。事件觸發型內容（新聞稿、通函）為 null。
cdc:versionstring | null文件版次（例如 114.04.16 或 v17）。非文件類內容為 null。
cdc:isCurrentboolean是否為現行版。文件家族內生效日最新且已發布者為 true；false 代表已被取代，AI 不得引用。
cdc:supersededBystring | null取代本版的新版 id；現行版為 null。由系統依 effectiveAt 計算，不手填。
cdc:aiWhitelistboolean是否在 AI 白名單內（已發布、未逾期、未被取代、未落後於正本、敏感度為 public、型別獲准）。不是 true 的內容 AI 不會引用。
cdc:licensestring授權代碼：OGDL-1.0（政府資料開放授權條款第 1 版）、CC0-1.0、CC-BY-4.0。
cdc:statusstring生命週期狀態：draft、review、published、archived。

授權與引用規範

預設授權為政府資料開放授權條款第 1 版（OGDL-1.0）：可自由重製、散布、修改、商業利用，但須標示來源。個別資料集若為 CC0-1.0 或 CC BY 4.0，會在該筆的 license 欄位寫明。政策頁：開放資料授權。

引用格式

請附上網址與最後審閱日；文件類再附版次與生效日。專業模式頁面的「引用本頁」按鈕會自動產生：

衛生福利部疾病管制署（2026-01-05 審閱）。傳染病病例定義：登革熱（2026 年版）。https://ancientsky.github.io/new_cdc_prototype/preview/pr-56/documents/case-definition-dengue.2026-01-01/（2026-01，生效 2026-01-01）

AI 系統引用時，請同時帶出 cdc:reviewedAt 與 cdc:isCurrent；若 isCurrent 為 false，應改引 cdc:supersededBy 指向的新版。

舊官網網址對照（內容移轉）

舊官網（www.cdc.gov.tw）上架的內容會依移轉清單逐筆對應到新頁。對照結果有四種輸出，都在建置時由同一份清單產生，不需手動維護：

檔案用途
/v1/legacy-map.json精簡對照，data 內為 { "/disease/subindex/…": "/diseases/dengue/" }。key 已正規化（小寫、無網域、無尾斜線、無 hash、去掉 page 參數、百分比編碼統一）；另有 patterns（{id} 佔位的 URL 模式）與 gone（不移轉，建議回 410）。404 頁與 /legacy/ 查詢頁即用它。
/redirects/nginx.mapNginx map $request_uri 用，一行一筆正規表示式對新網址，用法寫在檔頭註解。
/redirects/web.config.rewritemap.xmlIIS URL Rewrite 的 rewriteMap，貼進 web.config；署內現行官網若為 IIS 可直接用。
/redirects/_redirectsNetlify／Cloudflare Pages 格式：from to 301。

三個 redirects/ 檔都只收網址完整、已有去向的項目：{id} 佔位的 URL 模式、已不再提供（410）、同一舊網址對到多個新頁的不輸出（寧可不轉，也不轉錯）；移轉清單尚未核對（verified: false）者照常輸出但檔內標註，上線前請權責單位確認。/v1/redirects.json 另含 kind: "migration" 項與每筆的 verified 欄位。政策與關閉日見 舊網址查詢頁下方說明。
