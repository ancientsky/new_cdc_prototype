# 外國衛生人員申請疾管署國際訓練

> 權責單位：企劃組 · 最後審閱：2026-10-01 · 下次審閱：2027-10-01 · 授權：OGDL-1.0 · ID：service.international-training-application · 類別：other

外國衛生官員與專業人員可線上申請疾管署國際訓練（FETP 交流、研習營、實驗室、結核病都治、登革熱防治），30 日內回覆審查結果。

疾管署歡迎夥伴國家衛生官員與專業人員參加國際訓練：FETP 交流、國際研習營（含 GCTF）、實驗室訓練、結核病防治與都治、登革熱防治。

請線上填寫申請表，並附所屬機關或夥伴國駐臺代表機構推薦函。企劃組會同主辦單位審查，30 日內回覆。

- 誰可申請：外國政府衛生官員、經所屬機關推薦之公共衛生與實驗室專業人員、合作協定下之夥伴機構人員
- 處理天數：30 個工作天
- 費用：訓練免費；交通與住宿依各計畫規定。
- 聯絡：疾管署企劃組：總機 +886-2-2395-9825（上班時間）；防疫專線 1922（國外 +886-800-001922）

## 申請步驟

1. **選擇訓練計畫**（申請人）（0 日）：於國際訓練頁查閱計畫與年度時程。
2. **送出申請**（申請人）（0 日）：線上填寫申請表並上傳推薦函、簡歷與護照影本。
3. **審查**（疾管署）（21 日）：企劃組會同主辦單位審查。
4. **通知與安排**（疾管署）（9 日）：錄取者收到邀請函與行程安排；未錄取者亦會收到通知。

## 常見問題

### 參加訓練需要付費嗎？

訓練免費；交通與住宿是否補助依各計畫規定，並載明於邀請函。

### 個人可以不經推薦直接申請嗎？

申請通常需所屬機關或夥伴國駐臺代表機構推薦。
