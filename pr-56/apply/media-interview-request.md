# 媒體採訪與拍攝申請

> 權責單位：公關室 · 最後審閱：2026-04-01 · 下次審閱：2027-04-01 · 授權：OGDL-1.0 · ID：service.media-interview-request · 類別：other

媒體採訪疾管署業務、專家或拍攝影像，請提前 3 個工作日向公關室提出申請，載明主題、受訪對象需求與播出時間，由公關室協調安排。

疾管署公關室受理媒體採訪、專訪與拍攝申請。**每週例行記者會**之資訊與直播連結公布於新聞稿頁；緊急疫情回應請以電話聯繫公關室。

- 一般採訪請提前 **3 個工作日**申請。
- 進入實驗室、檢疫站等管制區拍攝，須另經權責單位同意並遵守生物安全規定。
- 本署新聞稿、圖片與影片依政府資料開放授權條款釋出，可直接引用並註明來源。

- 誰可申請：新聞媒體、影音製作單位、學術與教育單位
- 處理天數：3 個工作天
- 費用：免費
- 聯絡：疾病管制署公關室（總機 02-2395-9825 轉公關室）

## 申請步驟

1. **提出申請**（媒體）（0 日）：以電子郵件或表單送公關室。
2. **公關室協調權責單位**（公關室）（1 日）：依主題指派受訪單位。
3. **確認時間與形式**（公關室）（1 日）：回覆受訪者職稱、時間與地點。
4. **採訪與事後確認**（權責單位）（1 日）：必要時提供專業內容確認。

## 常見問題

### 可以指定由署長受訪嗎？

可以提出，但由公關室依主題與行程安排最適合的受訪者（職稱）。

### 可以使用疾管署的衛教影片片段嗎？

可以，依政府資料開放授權條款引用並註明出處；但請使用依現行版本製作之影片。
