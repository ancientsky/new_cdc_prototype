# 臺北區管制中心（Taipei Regional Center）

> ID：unit.regional-taipei · 類別：Regional centers · 負責內容 0 項、白名單 0 項

轄區：臺北市、新北市、基隆市、宜蘭縣、金門縣、連江縣。負責轄區防疫業務的督導、疫情調查與地方協調。

> 簡介為原型撰寫，尚待該單位確認。

## 主要業務

- 轄區疫情調查與督導
- 地方衛生局協調
- 轄區防疫宣導
