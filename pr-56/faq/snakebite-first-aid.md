# 被蛇咬怎麼辦？

> 權責單位：檢驗及疫苗研製中心 · 最後審閱：2026-10-10 · 下次審閱：2027-04-10 · 授權：OGDL-1.0 · ID：faq.snakebite-first-aid
> ⚠ 本頁依公開資料整理，尚待權責單位（檢驗及疫苗研製中心）逐項確認。緊急狀況請撥 119；用藥與處置以醫師判斷為準。

被蛇咬傷時，一律先當作毒蛇咬傷處理，保持冷靜並儘速就醫，緊急時請撥打 119。出現呼吸困難、意識改變或大量出血，請立即撥打 119。

請記住疾管署的「五要」：

1. 要視為毒蛇咬傷處理。
2. 要記住蛇的外觀特徵（顏色、花紋、頭形），方便醫護人員判斷。
3. 要儘快脫下戒指、手錶、手環等飾品，避免肢體腫脹後受到壓迫。
4. 要在傷口上緣做寬鬆包紮，減緩毒液擴散，包紮不可緊到阻斷血流。
5. 要保持冷靜，儘速就醫。

抗蛇毒血清是治療毒蛇咬傷最有效的方法，由醫師在醫療院所判斷與使用。
