# 開放資料授權與使用說明

> 權責單位：AI推動辦公室 · 最後審閱：2026-09-01 · 下次審閱：2027-09-01 · 授權：OGDL-1.0 · ID：page.open-data

## 一、授權條款
除另有標示外，本站文字內容、統計資料與 API 回傳資料，均依 **政府資料開放授權條款第 1 版**（Open Government Data License, version 1.0）提供。此條款與 CC BY 4.0 相容。

## 二、您可以
- 重製、改作、編輯、公開傳輸，或以其他方式利用，包含商業利用。
- 將資料與其他資料結合，製作衍生作品或服務（例如 App、AI 應用）。

## 三、您應該
- **標示來源**：例如「資料來源：衛生福利部疾病管制署（資料日 YYYY-MM-DD）」，並附原始網址。
- 不得以任何方式暗示疾管署為您的衍生作品背書。
- 引用手冊、指引時請標示版次，並確認為現行版。

## 四、例外
- 標示「授權待確認」或其他授權的資料集，以該資料集頁面標示為準。
- 第三方提供之圖片、影片或商標，不在本條款授權範圍。
- 個人資料與去識別前之原始資料不開放。

## 五、取得方式
- 資料目錄：本站「開放資料與統計」頁，每筆標示權責單位、更新頻率、最後更新日與授權。
- API：`/v1/` 各端點與 OpenAPI 文件；資料集原始檔請至疾管署資料開放平台下載。
- 統計查詢：傳染病統計資料查詢系統（NIDSS）。

## 六、品質與回饋
資料若有錯誤或延遲更新，請透過資料集頁面的回報功能告知，將轉請權責單位處理。
