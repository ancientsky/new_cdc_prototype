# 疑似傳染病群聚通報（民眾、學校、機構）

> 權責單位：疫情中心 · 最後審閱：2026-09-01 · 下次審閱：2027-09-01 · 授權：OGDL-1.0 · ID：service.cluster-report-1922 · 類別：notification

學校、機構或團體短時間內多人出現腹瀉、發燒、咳嗽等相似症狀時，請撥 1922 或通報轄區衛生局，衛生單位將協助調查與採檢。

短時間內（例如 3 天內）同一場所 **2 人以上**出現相似症狀，例如腹瀉嘔吐、發燒咳嗽、出疹，可能是傳染病群聚。

- **民眾**：撥打防疫專線 **1922**（國外 +886-800-001922），客服會轉知衛生局。
- **學校、托育、長照機構**：依各主管機關規定通報轄區衛生局，並啟動隔離、環境清消。
- 若有人症狀嚴重，請先就醫或撥 119。

- 誰可申請：民眾、學校與托育機構、長照與安養機構、企業與團體
- 處理天數：1 個工作天
- 費用：免費
- 聯絡：防疫專線 1922（國外 +886-800-001922；免付費 0800-001922）；疾病管制署總機 02-2395-9825

## 申請步驟

1. **撥打 1922 或通報衛生局**（民眾／機構）（0 日）：說明場所、人數與症狀。
2. **衛生局聯繫與現場評估**（地方衛生局）（1 日）：衛生局聯繫通報人，必要時到場。
3. **採檢與防治措施**（地方衛生局／區管中心）（2 日）：採集檢體、指導隔離與清消。
4. **結果回覆與結案**（地方衛生局）（14 日）：依檢驗結果研判並追蹤至無新增病例。

## 常見問題

### 只有家人一起拉肚子，需要通報嗎？

家庭內多為共同飲食，症狀輕微者先就醫即可；若懷疑來自餐廳或團膳，可撥 1922 或向衛生局反映。

### 通報後會公開學校或機構名稱嗎？

原則不公開，除非為防疫必要並依法定程序。
