# 哪裡可以做匿名 HIV 篩檢？

> 權責單位：慢性傳染病組 · 最後審閱：2026-06-10 · 下次審閱：2026-12-10 · 授權：OGDL-1.0 · ID：faq.hiv-test-where · 依據：disease.hiv

可以選擇：

- **匿名篩檢醫院**：不需健保卡，提供諮詢與檢驗。
- **社區篩檢點**：由民間團體與衛生局合作提供。
- **HIV 自我篩檢試劑**：可於指定藥局、販賣機或網路通路取得，部分對象可申請公費試劑。

自我篩檢結果陽性時，需到醫院做確認檢驗；若距離可能感染不到 3 個月，結果陰性也建議之後再篩一次（空窗期）。
