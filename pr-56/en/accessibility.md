# Accessibility statement

> 權責單位：資訊室 · 最後審閱：2026-09-15 · 下次審閱：2027-09-15 · 授權：OGDL-1.0 · ID：page.accessibility

We target the revised Taiwan Web Accessibility Guidelines at level **AA (aligned with WCAG 2.2 AA)**. September 2026 automated and manual tests (keyboard, NVDA, VoiceOver, 200% zoom) found the site conformant for headings, skip links, keyboard focus, 4.5:1 contrast, aria-live answers, native details/summary, chart text alternatives and language attributes. Partially conformant: some legacy PDFs (machine-readable Markdown provided; remediation by June 2027) and captions on pre-2024 videos (by March 2027). Report problems via the footer link or call 1922; we reply within 7 working days.
