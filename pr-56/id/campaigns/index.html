同一批 Banner 在首頁有兩種擺法，依疫情狀態自動選用（原型預覽：首頁網址加 ?hero=A 或 ?hero=B 可強制切換）。圖只當氛圍，字都在 HTML，首屏永遠是問題框與疫情狀態。

  • 做法 A · 分割式（非高峰）

    左：問題框；右：本期宣導大圖卡（16:9 滿卡寬），字在圖下方，最多 3 則輪播。看真實首頁 →

  • 做法 B · 情境式（疾病高峰自動切換）

    首屏白色面板講疫情與建議，右側用宣導大圖當氛圍；宣導卡退到疫情狀態卡下方（圖左 40％＋文字右）。看真實首頁 →

Governance rule Banners come down automatically when they expire and, like any other content, have an owner and a review date. Images are decoration only; all text is on the page.
