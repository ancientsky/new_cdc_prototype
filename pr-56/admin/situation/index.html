疫情發布

疫情中心在這裡發布首頁的「現在的疫情」：每種疾病四級狀態、趨勢、指標、近週數字、一句話建議，以及這張首頁卡要用哪種樣版。狀態由疫情中心依既有監測門檻判定，不由模型推論；表單即時預覽首頁卡片。

正式環境：填寫 → 匯出 situation/current.json（舊檔自動進 situation/history/）→ 疫情中心開 PR → CI 驗證 schema 與主檔 → 核定後合併即發布首頁、/situation/ 與 /v1/situation.json。

目前發布：2026-09-21（資料日 2026-09-21，距今 10 日）下次審閱日 2026-09-28，已逾期：前台態勢層會顯示「最後更新」警示，並已產生待辦給疫情中心。
