人才招募上架與異動

人事室在這裡上架新職缺、延長報名或改甄試日、取消或標示已補實，以及公告錄取名單（正取、備取、遞補）。每次輸入都即時預覽前台階段與日期，並用與建置相同的規則檢核；報名編號不合格的列會標紅；甄選結果只公布報名編號（不公布姓名），並且一定要有下架日。

正式環境：填表 → 右側檢核全過 → 匯出 JSON，新增或覆蓋 content/jobs/ 下的同名檔 → 開 Pull Request。職缺走快車道：CI 通過即自動合併上線（約 3 分鐘），上線後 24 小時內完成上線後複核（待辦給公關室，副本人事室）。

異動會留下紀錄改報名或甄試日期、取消、補實時，表單會在 amendments 追加一筆「異動紀錄」（日期、類型、給民眾看的一句話、字號），前台職缺頁的「公告異動」區依日期倒序列出，民眾看得到歷程。日期改了卻沒加紀錄，右側會提醒。
