# 孩子腸病毒好了，什麼時候可以回學校？

> 權責單位：急性傳染病組 · 最後審閱：2026-09-24 · 下次審閱：2027-03-24 · 授權：OGDL-1.0 · ID：faq.enterovirus-return-school · 依據：doc.ev-childcare-guideline

確診手足口病或疱疹性咽峽炎的孩子，**請在家休息至少 7 天**。返校前，請確認孩子已退燒、可正常進食，口腔潰瘍與水泡明顯改善。

腸病毒在痊癒後仍可能從腸道排出病毒達數週，因此返校後家長與老師仍要提醒孩子**如廁後、用餐前用肥皂洗手**，並避免共用杯子與玩具。若孩子回到學校後再度發燒或有重症前兆（嗜睡、肌躍型抽搐、持續嘔吐），請立即就醫。
