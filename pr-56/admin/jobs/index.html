人才招募管理

人事室的招募職缺總覽：每則職缺目前在哪個階段、倒數、報名方式（站內模擬報名或外部系統）、待辦，以及甄選結果上架前的檢核。

正式環境：職缺是 content/jobs/ 的 job 檔。上架新職缺、延長報名或改期、取消／補實、公告錄取名單與遞補，都用「上架與異動」表單填寫並即時檢核，匯出 JSON 後開 PR（快車道，CI 過即自動合併）；改期與取消會留下異動紀錄給民眾看。階段由日期與 result 欄位推導，截止當天、甄試日到期都不需要任何人動手；結果上架時建置會強制檢查遮罩姓名。

結果只公布報名編號、到期下架；建議名單留在人事系統 第三十輪起 result.admitted／waitlist／waitlistUpdates 只能有序號／順位、candidateNo（不得像身分證字號）與備取有效期，不得有任何姓名欄（連遮罩姓名 nameMasked 也不行）；result.unpublishAt（下架日）必填，當天起網站、API、RSS 與搜尋自動停止顯示名單，下架前 14 日會開待辦。違反時建置失敗，不能上線。名單一旦進 Git 就永遠留在歷史裡，所以建議只填 result.externalUrl（人事系統的結果頁或它託管的 PDF），JSON 不放名單。AI 問答不會唸出名單，只給結果頁連結。
