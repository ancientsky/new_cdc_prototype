# Request for notifiable disease case data (research)

> 權責單位：Epidemic Intelligence Center · 最後審閱：2026-08-20 · 下次審閱：2027-08-20 · 授權：OGDL-1.0 · ID：service.case-data-request · 類別：data-request

Researchers may request de-identified case data with a research protocol and IRB approval; review takes about 30 days.

疾管署依《傳染病防治法》及《個人資料保護法》，提供**去識別化**之法定傳染病個案資料供學術研究使用。資料僅限於核准之研究目的，**於本署資料專區（或遠端分析環境）內使用**，攜出結果須經檢核，不得嘗試再識別個人。

已公開的彙總統計請先查詢開放資料與 NIDSS，不需申請。

- 誰可申請：研究者、學研機構、醫療院所研究單位
- 處理天數：30 個工作天
- 費用：依資料專區使用規費標準收費（示意）
- 聯絡：疾病管制署疫情中心（總機 02-2395-9825）；一般諮詢請撥防疫專線 1922（國外 +886-800-001922）

## 申請步驟

1. **確認公開資料是否足夠**（申請人）（0 日）：先查 NIDSS 與開放資料平臺，彙總統計不需申請。
2. **線上送件**（申請人）（1 日）：填寫申請書並上傳應備文件。
3. **形式審查**（疫情中心）（5 日）：檢查文件完整性，不全者通知補件（補件期間不計入處理天數）。
4. **實質審查**（資料審查小組）（20 日）：審查變項必要性與去識別化程度，必要時召開審查會議。
5. **核定與資料提供**（疫情中心）（5 日）：核定後簽署使用約定，於資料專區開通使用帳號。

## 應備文件

- [ ] 申請書（載明研究題目、所需變項與年度）
- [ ] 研究計畫書
- [ ] 人體研究倫理審查委員會（IRB）核准證明
- [ ] 資料使用切結書
- [ ] 計畫主持人所屬機構同意函

## 法源

- 傳染病防治法
- 個人資料保護法第 16 條
- 政府資訊公開法

## 常見問題

### 可以拿到有姓名或身分證字號的資料嗎？

不可以。研究用資料一律去識別化，且只提供研究必要之變項。

### 學生可以申請嗎？

可以，但須由指導教授擔任計畫主持人，並檢附 IRB 核准證明。

### 30 日從什麼時候開始算？

自文件齊備之日起算，補件期間不計入。
