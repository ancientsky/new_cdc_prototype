# 預防醫學辦公室（Office of Preventive Medicine）

> ID：unit.preventive-medicine · 類別：署長室與幕僚室 · Steward：Data Steward（預防醫學、健康促進） · 負責內容 0 項、白名單 0 項

任務編組。負責防疫醫師與流行病學人才培訓、旅遊醫學等專業諮詢，以及特殊傳染病個案或群聚的調查分析與用藥審查。

> 簡介為原型撰寫，尚待該單位確認。

## 主要業務

- 防疫醫師及流行病學人才之培訓，並提供旅遊醫學等專業諮詢
- 特殊傳染病個案或群聚案件之調查分析
- 特殊傳染病病歷審查及申請用藥之審查

出處：衛生福利部疾病管制署處務規程（依公開法規摘錄整理，待逐字核對）
