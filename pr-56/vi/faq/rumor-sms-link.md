# 收到自稱疾管署的簡訊要我點連結填資料，怎麼辦？

> 權責單位：公關室 · 最後審閱：2026-09-16 · 下次審閱：2027-03-16 · 授權：OGDL-1.0 · ID：faq.rumor-sms-link · 依據：clar.2026-09-anti-epidemic-team-scam

疾管署**不會以簡訊或通訊軟體要求民眾點連結填寫個資、信用卡或帳戶資料**，也不會要求匯款或投資。收到這類訊息請不要點連結、不要回覆，可撥打 165 反詐騙專線查證，或撥 1922 防疫專線詢問。

疾管署的官方資訊以官網（cdc.gov.tw）及官方社群帳號公告為準。
