# 性傳染病匿名諮詢與篩檢

> 權責單位：慢性傳染病組 · 最後審閱：2026-06-10 · 下次審閱：2026-12-10 · 授權：OGDL-1.0 · ID：topic.anonymous-testing

**匿名篩檢**：全國指定醫院提供 HIV 匿名篩檢與諮詢服務，不需健保卡、不留真實姓名，以代號登記；同時可詢問梅毒篩檢與 PrEP。

**自我篩檢**：可透過自動服務機、合作藥局或網路購買 HIV 自我篩檢試劑，部分族群符合條件可享優惠。結果陽性請至醫院做確認檢驗。

**空窗期提醒**：距離危險行為時間太短，陰性結果不代表沒有感染，請依說明再次篩檢。

**陽性怎麼辦**：個案管理師會協助轉介愛滋指定醫院，及早治療可達到病毒量測不到（U=U）。
