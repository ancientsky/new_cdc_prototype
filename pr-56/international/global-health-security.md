# 全球衛生安全：抗藥性、疫苗與邊境檢疫

> 權責單位：企劃組 · 最後審閱：2026-10-01 · 下次審閱：2027-10-01 · 授權：OGDL-1.0 · ID：page.international-global-health-security

全球衛生安全取決於每個夥伴的偵測、預防與應變能力。疾管署在三個領域貢獻：

- **抗微生物製劑抗藥性（AMR）**：以一體健康（One Health）監測醫院與社區抗藥性菌株、推動抗生素管理計畫與專家交流；見[抗藥性與一體健康專區](/topics/amr-one-health/)。
- **疫苗**：疫苗可預防疾病監測、緊急時期疫苗供應合作、分享預防接種計畫經驗；見[疫苗](/vaccines/)。
- **邊境檢疫**：依 IHR 建置指定機場、港口的核心能力，合作處理有症狀旅客與交通工具，並發布各目的地旅遊疫情建議；見[國際旅遊疫情建議](/travel/)。

> 以上為持續進行工作的摘要；個別協議列於[雙邊合作頁](/international/bilateral/)。
