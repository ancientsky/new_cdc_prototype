How to apply

Applications closed; results were announced on Sep 22, 2026. Selection results →

Duties

  • 官網與開放資料平台之需求分析與系統設計
  • API 規格管理與版本控管
  • 資訊安全管理與弱點改善追蹤
  • 網站無障礙檢測與改善

Qualifications

  • 國內外大學以上資訊工程、資訊管理或相關學系畢業
  • 具 3 年以上系統分析或系統設計實務經驗
  • 熟悉 RESTful API、OpenAPI 規格與關聯式資料庫
  • 具資訊安全（ISO 27001）或網站無障礙檢測經驗者優先

Salary and benefits

比照行政院暨所屬機關約用人員薪點，資訊類 430 薪點起敘（依學經歷核定，示意）

Required documents

  • 履歷表（含自傳）
  • 最高學歷畢業證書影本
  • 工作經歷證明
  • 專業證照影本（有者檢附）
