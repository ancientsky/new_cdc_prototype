# 被蛇咬後能不能冰敷、綁止血帶或用嘴把毒吸出來？

> 權責單位：檢驗及疫苗研製中心 · 最後審閱：2026-10-10 · 下次審閱：2027-04-10 · 授權：OGDL-1.0 · ID：faq.snakebite-dont
> ⚠ 本頁依公開資料整理，尚待權責單位（檢驗及疫苗研製中心）逐項確認。緊急狀況請撥 119；用藥與處置以醫師判斷為準。

都不建議。疾管署提醒被蛇咬傷的「五不」：

1. 被蛇咬傷不割開傷口，以免感染。
2. 被蛇咬傷不用嘴吸傷口的毒液，以免感染。
3. 被蛇咬傷不冰敷，以免組織壞死。
4. 被蛇咬傷不喝酒或刺激性飲料，以免加速毒液作用。
5. 被蛇咬傷不延誤就醫，以免耽誤治療時機。

醫師也常提醒：被蛇咬傷不綁止血帶或橡皮筋，阻斷血流可能造成肢體缺血壞死；被咬的手腳儘量固定、減少活動（此項待權責單位確認是否納入官方建議）。最重要的是儘速就醫，緊急請撥 119。
