# 研究計畫成果與研究資料申請

> 權責單位：企劃組 · 最後審閱：2026-08-20 · 下次審閱：2027-08-20 · 授權：OGDL-1.0 · ID：service.research-data-request · 類別：data-request

申請疾管署委託或自行研究計畫之成果報告全文、研究資料集與分析程式，說明可提供範圍、應備文件與審查流程，處理期間約 20 日。

疾管署委託及自行研究計畫之**成果報告摘要**公開於研究計畫專區；如需報告全文、研究資料集或分析程式，可提出申請。涉及個案層級資料者，另依「傳染病個案資料申請」辦理。

- 誰可申請：研究者、學研機構、政府機關
- 處理天數：20 個工作天
- 費用：免費
- 聯絡：疾病管制署企劃組（總機 02-2395-9825）；一般諮詢請撥防疫專線 1922（國外 +886-800-001922）

## 申請步驟

1. **查詢研究計畫專區**（申請人）（0 日）：確認計畫編號與是否已公開。
2. **提出申請**（申請人）（1 日）：以申請書載明所需項目。
3. **會辦計畫承辦單位**（企劃組）（10 日）：確認資料可提供範圍與智慧財產權限制。
4. **回覆與提供**（企劃組）（9 日）：以電子方式提供或說明不能提供之理由。

## 常見問題

### 研究計畫成果報告都會公開嗎？

結案計畫原則公開摘要；全文依計畫性質與合約約定公開或提供申請。

### 可以申請正在執行中的計畫資料嗎？

執行中計畫尚未驗收，原則不提供，請於結案後申請。
