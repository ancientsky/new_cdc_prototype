# 資訊室（Information Management Office）

> ID：unit.it · 類別：署長室與幕僚室 · Steward：平台與資安 · 負責內容 4 項、白名單 1 項

維運網站平台、資訊安全與帳號權限。在新架構中負責 Git 代管平台、CI、靜態主機、後台登入（SSO）與稽核紀錄。

> 簡介為原型撰寫，尚待該單位確認。

## 主要業務

- 網站平台與靜態主機維運
- 資訊安全、帳號與登入（SSO／MFA）
- 後台稽核紀錄保存與調閱
