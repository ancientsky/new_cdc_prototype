# 防登革熱說的「巡、倒、清、刷」是什麼？

> 權責單位：急性傳染病組 · 最後審閱：2026-07-20 · 下次審閱：2027-01-20 · 授權：OGDL-1.0 · ID：faq.dengue-container-check · 依據：disease.dengue

「巡倒清刷」是清除病媒蚊孳生源的四個步驟，建議**每週做一次**：

1. **巡**：巡視住家室內外可能積水的容器，如花盆底盤、水桶、廢輪胎。
2. **倒**：倒掉積水。
3. **清**：清除不需要的容器。
4. **刷**：刷洗容器內壁，去除斑蚊蟲卵。

斑蚊從卵到成蚊約 7–10 天，每週清一次就能中斷繁殖。

## 結構化欄位
- frequency: 每週一次
