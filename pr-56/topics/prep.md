# PrEP 暴露愛滋病毒前預防性投藥計畫

> 權責單位：慢性傳染病組 · 最後審閱：2026-06-05 · 下次審閱：2026-12-05 · 授權：OGDL-1.0 · ID：topic.prep

PrEP 是在可能暴露 HIV **之前**服用抗病毒藥物，正確使用可大幅降低經性行為感染的風險。

**誰適合**：近期有無套性行為、伴侶為未穩定治療之感染者、曾罹患性傳染病或曾使用 PEP 者，可與 PrEP 合作醫院醫師討論。

**怎麼開始**：預約合作醫院 → 抽血確認 HIV 陰性、腎功能與 B 型肝炎 → 醫師評估每日或事件型服藥 → 每 3 個月回診追蹤。

**補助**：符合計畫條件者可獲藥費或檢驗費補助，名額與條件以當年度公告為準（示意）。
